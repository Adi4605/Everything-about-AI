- Coefficient of Determination
- Measures how well a regression model explains the variation in the target variable.
- Tells how much of the variability in the actual target values is explained by the model.

-  SSE -> Residual Sum of Squares
- SST -> Total Sum of Squares

- Higher R² -> Better Fit

- **R² = 1 → Perfect fit**
- **R² = 0 → Mean baseline performance**
- **R² < 0 → Worse than the mean baseline**
